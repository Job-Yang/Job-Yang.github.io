给 Agent 做记忆,说白了就是给一个"每次上工都失忆的临时工"配个归档助理。拆开看是四块:怎么存、怎么抽、怎么检索路由、怎么维护。市面上四大流派各玩各的——流式反思、分层分级、知识图谱、复合混合,没谁通吃。整篇调研看下来最反直觉的一条:没有银弹,只有"对不对得上你的场景";保真度比压缩度金贵,宁可多存原文也别急着概括;维护也是,先补局部,别一上来就全局重整。工程和学术压根是两套目标函数,选型别对着论文榜单抄。这套东西落到我这儿——iOS Agent 缺的运行时状态、跨仓检索、业务链路,不就是"记忆"要去补的那几个洞么。
