聪明人没趁手的工具也干不了精细活，AI 也一样。思路不是把模型调得更聪明，而是给它足够多趁手的工具 —— 内置工作流（怎么想）+ 内置工具（怎么做）+ 取证手段（怎么看），再用 playbook 约束什么场景抽哪几把、怎么组合。验数据看日志 / 抓包，验 UI 看视图树 / 截图，验 crash 看 crash report。模型本身没变，但工具够多、组合够对，它在具体任务上就肉眼可见地变聪明了。能编译能跑能看日志能看 UI 的 Agent，和只能读代码文本的，不是一个物种。而且这事有复利：**后续不是调教模型，而是不断加工具、磨实践 —— 它的能力上限，是被我们的工具和经验一直往上抬的。**
