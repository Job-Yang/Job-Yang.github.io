# 序章：新的发钞机

2026 年的大厂正在干一件挺反常的事：抢着把 Token 塞进员工手里。

没有额度表，不用走审批，写代码、跑数据、做调研尽管使劲调。用得越多主管越高兴，觉得你在拥抱 AI。一个工程师一个月烧掉的 Token 折算成 API 账单上千美金，公司眼睛都不眨。

天下哪有长期免费的午餐。当一样东西被无限量、不要钱地塞给你用，值得停下来问两句：到底谁在印它？印的人图什么？

《货币战争》讲穿了一套老规律：最大的权力不在你账上有多少钱，而在你能不能印钱。握住发钞权的一方，可以先拼命放水让所有人狂欢，等大家都加满杠杆、离开钱转不动，再猛地收紧银根，把泡沫连同真实财富一起卷走。

放水、养依赖、收紧、收割，这是一整套周期。眼下，一台新的印钞机正在轰鸣，印的是 Token，坐在机器前面的，就是握着底座大模型的那几家公司。

大厂发「无限量 Token」绝非终点，反而是周期的起点。眼前的狂欢是放水期特有的热乎劲，回旋镖已经在路上了。

# 第一章：谁握着新世界的发钞权

Token 已经实质上扮演了货币的角色。在 AI 这套闭环经济里，它几乎是唯一的计价单位：调一次模型、吐一段字、跑一轮推理，按 Token 计费、结算、也按它算投入。

既然成了货币，就有发钞权。极少数基础模型厂商手握三根操纵杆，和央行手里那几根几乎一一对应：

- **定价权：**每百万 Token 卖多少钱，说涨就涨、说降就降，对应利率。
- **限流权：**给多少并发、放多长上下文、高峰期降不降级，随时可调，对应准备金率。
- **迭代权：**模型什么时候更新、老版本什么时候停服下线，厂商说了算，对应发行节奏。

三权合一，模型厂商就是这个新世界的央行。今天它可以贴钱把 Token 卖得比成本还低，明天也能一纸公告涨价三倍、把你依赖的旧版本直接下线。一旦整套业务和工作流都焊在它的底座上，你连讨价还价的牌都没有。

> 《货币战争》有句老话：控制了一国货币发行，就不在乎谁立法律。换到今天也差不多：控制了 Token 发行，就不在乎你的业务到底长成什么样。

# 第二章：无限量供应背后的公地悲剧

先打掉一个顺手乱套的错觉：有人说「Token 越印越多，单份含金量不就被稀释了吗？」这个类比是错的。法币会通胀，因为大家抢同一池子货物；Token 各跑各的算力，你多烧十万 Token 不会让我手里的 Token 贬值。

真正要命的机制在下面两条，比通胀狠得多。

## 公地悲剧：对个人免费，对集体天价

![这张插画直观呈现了Token供应下的公地悲剧核心逻辑：画面顶部的橙色云朵标注“免费Token”，不断向下洒落带字母T的金币Token。左上角绿色标识标注“个人成本：零”，五个白身黑面的机器人形象人物正毫无节制地捡拾、收集散落的Token，地面上已经堆起多堆大量的Token。右上角红色警示标识明确标注“集体账单：天文数字”，画面底部配文“公地悲剧：免费对个人，昂贵对集体”，呼应了文档中员工无成本滥用免费Token，最终累加形成巨额集体成本的相关论述。](/assets/content/token战争/02-image-2-d86149de.png)

公司对员工敞开供应 Token 后，每个人的理性选择都是「能多跑就多跑」。反正不扣自己的钱，让 Agent 多试几条路只有收益没有成本。可把几万个人的「多跑几条」加总，账单就成了天文数字。一片免费的公共草地，每个牧民都拼命多放几只羊，结果必然是把草啃秃。

只要消耗对个人完全无痛，用量就会不可避免地膨胀到远超它创造的价值，这和个人觉悟无关，是激励机制的必然结果。

## 探索学费：烧掉的 90% 不全是浪费

账单里烧掉的那 90%，其实混着两笔性质完全不同的钱。一笔是**纯挥霍**，拿不要钱的算力反复空转、跑些明知无用的杂活，这是公地悲剧的直接水漂。另一笔是**探索学费**，要想淘出真正提效的 10% 用法，必须先用另外 90% 的试错去蹚路，哪条链路值当，事先没人知道。

大厂肯咬牙买单，是被焦虑推着走的。谁先跑出能复制的提效范例，谁就抢到下一轮船票，所以只能拿「全员铺量」买「少数最优解」。等解法摸清、规范固化下来，探索期一结束，敞开的水龙头也就到了该拧紧的时候。

这正好对上放水第一步：用极低门槛让所有人先狂欢起来，先把依赖养进日常习惯里。

# 第三章：有用的东西，一样会崩

一提泡沫，很容易被当成唱空 AI。恰恰相反，AI 确实是新一轮工业革命，这点我不怀疑；但「真有用」和「有泡沫」常常同时存在。

2000 年互联网泡沫崩掉时，无数人骂互联网是骗局。后来呢？互联网确实改写了整个世界，但 1999 年市场把它的**估值拉得太快**，远远甩开了它**现金流兑现的速度**。估值跑到了终点，利润还在起点，中间那段虚空崩断的那天，就是泡沫破裂。

今天的 AI 跑在同一条赛道上。一头是融资、估值、算力基建靠叙事猛涨的速度；另一头是 AI 真能替代多少人工、收回多少真金白银的落地速度。

> 所有悬念都压在一个时间差上：技术兑现利润的速度，能不能赶在资本耐心耗尽前把估值填实？填得上，软着陆；填不上，就得重演一遍互联网危机。

眼下还很难赌技术兑现一定跑得赢估值。因为紧跟着两头压成本的大山，一座在账本里，一座在电网和水管里。

# 第四章：藏在折旧表里的次贷

翻开数据中心的财务报表，这里埋着一颗比估值更隐蔽的雷。

## 账面利润，全靠把芯片寿命往长里算

顶级算力卡单价极高，数据中心要把买卡的钱摊进每年的折旧里。折旧年限拉得越长，每年摊掉的成本就越低，利润表就越好看。

问题就出在这里：很多算力中心把芯片折旧拉到了六年甚至七年以上，只有按这么乐观的年限，整盘生意才算得平账。也就是说，眼下看到的漂亮盈利，很大一部分是用「假设芯片能用七年」算出来的。

## 可芯片根本挺不到第六年

算力卡换代快得吓人，英伟达已经把新架构从两年一代压到了一年一代。

去年天价买来的旗舰卡，明年虽然物理上没坏，但性能和能效比早被新品甩开，继续留着跑反而亏电费，业内普遍认为它的真实有效寿命更接近两到三年[［CNBC：GPU 折旧之争］](https://www.cnbc.com/2025/11/14/ai-gpu-depreciation-coreweave-nvidia-michael-burry.html)。

六七年的账面折旧撞上两三年的真实寿命，差出来的成本没消失，只是被推迟到后面确认——本质上是一笔藏进明后年的暗亏。

当年做空次贷的迈克尔·伯里在 2025 年 11 月做过一笔测算：几家大厂按五到六年折旧 GPU，而产品实际周期只有两到三年，2026 到 2028 年间被少计提的折旧、虚增的账面利润累计可能高达 **1760 亿美元**[［Michael Burry：1760 亿美元折旧低估］](https://uk.finance.yahoo.com/news/michael-burry-warns-176-billion-174008132.html)。如果这笔账成立，现在财报上的不少利润其实是账期魔术变出来的。

## 和次贷一模一样的剧本

![这张对比图直观呈现了2008年次贷剧本和2026年折旧剧本的同构逻辑。2008年次贷板块依次展示标注“还不起”的房屋、堆叠的房产文件与标准化金融产品盒，搭配先升后骤降的走势曲线，对应报表健康、加杠杆买房，最终房价崩盘链条断裂的过程。2026年折旧板块对应展示标注“两三年真寿命”的GPU芯片、标注“折旧年限6-7年”的财务报表，搭配走势形态高度相似的先升后骤降的曲线，对应报表盈利、加杠杆买芯片，最终芯片贬值、亏损爆发的过程。图底部点明核心结论：折旧暗雷与次贷完全同构，把该认的成本用假设推迟，最后集中爆发。](/assets/content/token战争/03-image-3-e148b03e.png)

次贷危机的套路，是把还不起的风险打包藏进复杂金融结构，让今天的账面看上去健康无比，等房价停涨再一窝蜂炸掉。

折旧暗雷走的是同一条路：把早该计提的损耗推迟到未来，用漂亮报表继续加杠杆囤卡。等芯片一旦贬值过快、迭代红利接不上，亏损就会集中冒出来。就算老卡退下来还能拿去做推理，身价也早打了对折，远没有纸面上那么高枕无忧。

> 一旦真实折旧被迫入账，Token 单价就没法继续维持白菜价。而涨价，正是收割周期里最关键的拐点。

# 第五章：电力和淡水的物理极限

这波狂欢常给人一种错觉：只要肯烧钱，算力可以无限往外堆。但物理世界不认 PPT。

## 真正的硬约束：电和水

卡只要肯花大价钱还买得到，真卡住手脚的是电力和淡水。美国建得出数据中心，却配不出那么多配套供电，电网成了头号瓶颈；大机房散热又要吃掉海量淡水，这也是实打实的自然资源上限。

中美两边卡的地方正好反过来：美国有卡缺电，中国电相对充裕却卡在先进算力上。两边各有短板，正好印证算力底子死死拴在实体资源上，光靠印钱堆不出来。

## 今天的算力账单，才刚刚是个零头

还要看到，现在烧电烧水的还主要只是语言模型和普通 Agent。真要往下走到物理世界的实时交互模拟，需要的计算量比今天还高出几个数量级。我们连语言模型这一关的电和水都还没摸平，真正的算力大户还在后头。

> 折旧终归要入账，电和水又硬卡着上限，便宜的 Token 撑不了太久。

# 第六章：两层回旋镖

前头的线索拧到一起：放水养出依赖，折旧和物理成本又注定未来要涨价。价格一掉头，收割会顺着两条线往下落。

## 第一层：企业发 Token，先帮自己跑通替代方案

大厂今天给员工不限量用 AI，为的是尽快摸清每个岗位哪块能交由 AI 接管、怎么接最划算。

等员工拿这些免费额度把最优工作流一遍遍跑通、固化下来，回旋镖就飞回来了：最先失去议价权的，正是亲手把模型调教熟练的那批人。

## 第二层：模型厂商贴钱卖 Token，再收割整个行业

Claude Code 和 ChatGPT 的重度套餐定价这么低，因为厂商本来就在亏本抢习惯。奥特曼自己公开承认过，连每月 200 美元的 ChatGPT Pro 都在亏钱卖，重度用户用得远超预期[［Fortune：奥特曼称 200 美元订阅在亏钱］](https://finance.yahoo.com/news/sam-altman-says-losing-money-080700756.html)。

这和当年互联网烧补贴一模一样：先用低价让你离不开，等各行各业的流程全都拆不掉它了，再站上价值链顶端拿走大头利润。

落到个人头上也一样好算：你今天工作流里最离不开的那个模型，三年后要是涨价十倍，你换得掉吗？

## 越过提效临界点，省钱变亏钱

眼下低价期，算力成本比人力低，用 AI 就是省钱。等真实折旧入账、算力涨价越过临界点，机器跑一趟反倒比人贵时，用它反而亏钱。可那时候原来的熟练员工早就裁了、旧流程早就拆了，退路一断，涨价也得咬牙认账。

> 低价把退路一条条拆光，等没路可退时，发钞的人就开始收租。

# 第七章：卖铲子的人也下了场

淘金热里最稳的本来是卖铲子的英伟达，不管下游哪家模型赢，都得买它的卡。

但它没忍住只赚卖铲子的钱，开始拿资金四处深度绑定、投资下游算力与模型公司。这么一来，它就把旱涝保收的确定性，和「下游到底能不能挖出真金子」的风险捆在了一起。泡沫真破那天，卖铲人自己也躲不进避风港。

而撑起上面所有亏损补贴和交叉投资的，只有一件事：离谱的估值带来极易到手的融资。融来的钱补贴 Token、养出依赖、讲更大的故事推高估值，继续融资。只要真实盈利赶不上估值膨胀，这条链子迟早绷断，补贴一停，价格立刻打回原形。

> 员工靠补贴跑出替代自己的解法，行业靠低价换掉原有退路，背后那笔补贴全来自估值加杠杆的融资游戏。

# 终章：八个环节一一对上

把前面这七步连成一条线，你会发现和《货币战争》里的金融收割周期严丝合缝，八个环节全能对上：

![这张图清晰呈现了货币战争的金融循环与Token战争的AI循环，二者遵循同套发钞权逻辑，共有八个一一对应的环节，分别是收钞、收割、发钞权、放水、养依赖、吹泡沫、藏暗雷、撞天花板，两个循环通过双向箭头相连，直观呼应了前文“八个环节全能对上”的表述，图中举着放大镜的机器人旁的文字，进一步点明“八个环节一一对上，不是巧合”的核心观点。](/assets/content/token战争/04-image-4-d62b9671.png)

1. **掌握发钞权：**金融周期里是垄断印钞；Token 周期里是头部模型厂商卡住定价、限流和版本迭代。
2. **放水：**那边是低利率宽信贷鼓励借钱；这边是不限量超低价鼓励全员狂用。
3. **养依赖：**那边是家庭和企业加满杠杆离不开信贷；这边是个人和行业重构整套工作流，离了模型转不动。
4. **吹泡沫：**那边靠信贷推高资产价格；这边靠未来叙事推高估值，撑起百亿补贴。
5. **藏暗雷：**那边把次贷风险包装藏进报表；这边拿六七年长折旧掩盖芯片贬值。
6. **撞天花板：**那边债务撑破实体经济承受力；这边算力撞上电网和淡水的物理上限。
7. **收紧：**那边猛然加息抽银根；这边补贴退坡、真实折旧入账，Token 大幅涨价。
8. **收割：**那边资产打折甩卖、财富聚向发钞方；这边退路拆光只能硬吞涨价，利润流向话事人。

对得这么齐不是巧合，因为发行通用交换媒介的权力逻辑本来就相通。

> 谁握着通用交易媒介的印钞机，谁就能靠「先放水、后收紧」的节奏，把整条链条的利润往自己手里聚。

所以别光顾着问「AI 会不会抢我饭碗」，先想想印钞机真拧紧那天，你手里还有没有不求人、能切换的底牌。享受低价红利没问题，但别把核心流程焊死在单一家厂商上。

算提效也别只按今天打折后的账算，拿它乘以五倍、十倍去验一下底线，涨价之后还算不算得过账。

眼下低价补贴还没停，各家对模型的依赖还在往上叠，但这两件后续后果跑不掉：被跑通的环节需求会缩水，补贴退潮后的真实成本早晚要算回来。别在人人加杠杆狂欢时交掉自己的护城河，看懂周期的人，才会趁放水期先站稳自己的脚跟。

我是老羊。这回我不劝你离 AI 远点，只提醒你一句：用得趁手的时候，记得抬头看看是谁在印钞。
