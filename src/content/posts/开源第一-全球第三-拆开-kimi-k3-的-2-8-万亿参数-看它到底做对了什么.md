月之暗面刚开源的 Kimi K3，总参数 2.8 万亿，综合实力站到开源第一、全球第三。几个演示确实抓眼球：用开源 EDA 工具连续自主跑 48 小时搭出一块 4 平方毫米的芯片，还能渲染出类似《星际穿越》的黑洞效果。

不过比起热闹口号，我更想知道**这 2.8 万亿参数在架构上到底改了什么、算不算真前沿**。翻完官方技术报告、API 文档和关联论文后，这篇就专门拆开它的两块核心地基：稀疏 MoE 与混合注意力，尽量做到有基础的能看出取舍门道，没深抠过论文的也能明白强在哪里。

# 超稀疏 MoE：2.8 万亿参数里每次只动 1/175

先拆掉「2.8 万亿」带来的直觉误区。真要每次吐字把 2.8 万亿参数全过一遍算力，商业上根本跑不起。K3 走的是**稀疏 MoE（Mixture of Experts，专家混合）**，把庞大的前馈网络切分成大量小「专家」，每个词按需唤醒其中极小一部分。

具体规模是内部共 **896 个专家**，但每生成一个 token 只由路由器挑出 **16 个**干活，剩下 880 个全部休眠。折算下来，2.8T 总容量里单步真正参与计算的只有约 **1/175**。脑容量按大模型配齐，推理账单却按小模型来结，这才撑得住商用价格。

这条脉络里最关键的工业级铺路石是 DeepSeek。**DeepSeekMoE** 定下了两项沿用至今的套路：细粒度切分专家（fine-grained expert segmentation），并孤立出几个常驻的「共享专家」（shared expert）专门兜底通用知识，留出专业专家分工专精[[DeepSeekMoE]](https://arxiv.org/abs/2401.06066)。

到了 **DeepSeek-V3**，这个思路推到了 6710 亿总参数 / 370 亿激活，并用「无辅助损失」策略解决专家负载均衡问题[[DeepSeek-V3 Technical Report]](https://arxiv.org/abs/2412.19437)。

K3 把这条路线往更高稀疏度再压一步（896 选 16，激活比例明显低于 V3 的约 1/18），同时针对超稀疏训练最怕碰上的「路由坍塌、专家饥饱不均」，做了三项自研改造：

| 技术点 | 它在解决什么 | 做法 |
|-|-|-|
| **Stable LatentMoE** | 高稀疏度下训练容易不稳定 | 在隐空间做更稳的专家组织，让路由在极端稀疏下仍收敛 |
| **Quantile Balancing**  <br/>分位数均衡 | 传统负载均衡靠启发式更新 + 敏感的平衡超参，容易调崩 | 直接按路由分数的**分位数**分配专家，绕开超参调优，天然均衡 |
| **Per-Head Muon** | 大规模训练的优化器不够自适应 | 把 Muon 优化器细化到**按注意力头**独立优化 |

按官方给的效率账，这套组合拳下来，**相比上一代 K2 整体扩展效率提升了约 2.5 倍**。算力还是那些算力，但每次前向传播激活的参数都花得更值当。

# 注意力路线之争：K3 押了最硬的一条

如果说稀疏 MoE 算踩在行业成熟路径上，那么在注意力机制这块，K3 选了一条连很多大厂都还在观望的激进路线。这也是整代模型含金量最高的一块。

## 为什么注意力是长文本的命门

标准 Transformer 的自注意力，每生成一个新词都要回头和前面**每一个词**算两两关联度。序列长度记作 n，计算和显存开销按 **O(n²)** 飙升：长度翻一倍，开销直接翻四倍。把上下文拉到几十万 token 后，平方级的显存墙立刻就顶到了天花板。

解法叫**线性注意力**：不再让新词和全部历史词逐个握手，而是把历史压缩进一个定长「状态」里做滚动摘要，新词只跟这个固定状态交互，从而把复杂度从 O(n²) 降回 O(n)。这条路线几年来大致经历三代演进：

| 代际 | 核心机制 | 局限 / 代表 |
|-|-|-|
| 第一代 | 用带衰减的记忆向量做递归更新，旧信息按固定节奏淡忘 | 遗忘是"一刀切"的，记不住该记的（早期线性注意力 / RWKV 类） |
| 第二代 | 把记忆升级成一个**状态矩阵**，带衰减地累积信息 | 吞吐好，但仍缺"定点修改"能力（Mamba / Mamba-2） |
| 第三代 | 引入 **delta 规则**：告别无脑衰减，改为**定向擦除旧记忆、精准写入新记忆** | 更接近"可控的读写"（DeltaNet / Gated DeltaNet） |

## KDA：把第三代线性注意力再往前推一格

K3 的注意力核心叫 **KDA（Kimi Delta Attention）**，血统很明确，就是 **Gated DeltaNet 的升级版**。

先提一嘴 Gated DeltaNet：它把负责快速成片清空过时记忆的门控（gating）和负责定向修改特定内容的 delta 规则结合到一起，在语言建模与长上下文任务上打赢了 Mamba-2 和原始 DeltaNet[[Gated Delta Networks]](https://arxiv.org/abs/2412.06464)。

KDA 顺着这个思路做对了两步升级：第一，把过去全状态共用的单个衰减门控拆成**按通道独立调节（channel-wise）**，相当于给记忆矩阵每一维装上单独的遗忘旋钮，该忘的快忘、该留的慢忘；

第二，用 **DPLR（Diagonal-Plus-Low-Rank，对角加低秩）**转移矩阵刻画状态变化，保住细粒度读写的同时还能压扁计算开销，方便在硬件上铺开。这套方案最早系统提出于月之暗面的 **Kimi Linear** 论文，K3 把它搬上了旗舰规模[[Kimi Linear]](https://arxiv.org/abs/2510.26692)。

打个通俗比方：Mamba 那代的记忆机制像定时整块擦黑板，KDA 则给了模型一支精确到单个字块的橡皮。这也是它敢扛起 **100 万 token 上下文**的效率底气。

更值得留意的是，混合注意力已经成为目前顶流团队共同押注的公开路线，各家在记忆引擎上的取舍也已拉开层次：

| 玩家 | 线性注意力路线 |
|-|-|
| 阿里 Qwen3-Next | Gated DeltaNet |
| **月之暗面 Kimi** | **KDA + MLA（多头潜在注意力）** |
| 蚂蚁 Ling | Lightning Attention |
| 英伟达 Nemotron | Mamba-2 |

而且几家都不约而同收拢到同一套骨架：用「线性块 + 全注意力块」混搭，典型比例 **3:1**（每 3 个线性注意力层配 1 个全注意力层），Qwen3-Next 与 Kimi Linear 都走了这个配比。

线性层负责扛长上下文和省算力，少量全注意力层在需要精确召回的位置兜住精度。**多支彼此独立的团队收敛到同一个配方，说明它确实踩中了底层规律，不单纯是宣传口径。**

## AttnRes：让信息在深层网络里少走样

KDA 之外还有个搭档叫 **Attention Residuals（注意力残差，简称 AttnRes）**。传统深层网络里，各层表示靠均匀累加往下传，几十层下来，浅层的原始信号容易被反复覆写得模糊。

AttnRes 改成按需跨深度检索表示，好比在深层网络里架了一部直达浅层的电梯，尽量保住信息不失真；月之暗面还配了增强激活控制的 **SiTU（Sigmoid Tanh Unit）** 与提升注意力选择性的 **Gated MLA**。

# 除了架构，工程上怎么把成本压下来

光靠论文里的漂亮架构，未必能开出大众用得起的价格。K3 真正让超大开源模型跑出商用性价比的，是训练端与推理端两处扎实的工程取舍。

**训练端从 SFT 起就上量化感知训练：**权重用 MXFP4、激活用 MXFP8 直接进训练，跳过训完后再硬压的损耗。好比盖房子打地基时就按紧凑户型备好料，推理天然省显存，能跑在更常见、更便宜的卡上。

**推理端靠 Mooncake 分离式架构稳住高缓存命中：**在编程这类长前缀反复复用的任务里，缓存命中率能超 **90%**。国内 API 定价是输入命中缓存 **2 元/百万 token**、未命中 **20 元/百万**，输出 **100 元/百万**。

大面积命中缓存后，实际有效输入成本能降到标准价的约 **1/4**，而且 100 万 token 上下文统一按量计费、不按长度分档涨价。上下文顶到 100 万但账单没跟着暴涨，参数规模才真正算落了地。

# 水分在哪：把边界说清

夸完长处，边界一样要划清，才不会变成帮忙吹榜。K3 官方呈现里确实有需要注意的「水分」，主要出在挑选展示和评测口径上：

- **综合排名属于「全球第三档」，尚未追平最顶尖闭源。**中立第三方 Artificial Analysis 的综合智能榜把它放在第 3 档，前面还有 Claude Fable 5 和 GPT-5.6 Sol；官方稿里常提的「SOTA / 第一」，多来自单一细分榜单或自选口径。
- **部分高分带着特定前提。**例如信息搜索项 91.2 分，是开着 30 万 token 上下文压缩测出来的，和裸跑不可混为一谈；不同榜单套用不同评测框架，本身用的就不是同一把尺子。
- **惊艳 demo 属于精选展示，不代表稳定泛化水平。**芯片设计、编译器与黑洞渲染都进了 showcase，却不对应可复现的综合榜。尤其是黑洞画面，底层方程用的是爱因斯坦 1916 年就已推导出的史瓦西度规闭式解加零测地线光线追踪；模型做的其实是把成熟物理公式转成可运行代码并自己调通 bug，物理逼真源于公式本身，和模型「看懂黑洞物理」两回事。

所以别听「逼平世界第一」那种口号，客观定位就八个字：**开源第一，全球第三**。

# 「全球第三」已经很不容易

把边界摊开之后，如果把镜头拉远，开源第一、全球第三本身依然是一个很硬的结果。

变化最明显的，在于**和最强闭源模型的距离缩小到了以「月」为单位**，告别了早年差整代、差一两年的被动局面。更可贵的是，这段追赶靠的是一步步踩实架构创新（极限稀疏 MoE、KDA 注意力），而非表层刷榜调参。

月之暗面甚至把支持 prefill 缓存的 KDA 实现连同权重一起回馈进了 vLLM 开源生态，方便外部直接复用。模型能不能跑得远，靠的是敢在地基上下注、并能把新结构训稳的真功夫；照这个势头往下走，后面几个月确实值得期待。
