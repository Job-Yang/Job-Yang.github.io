大模型确实有智能，因为它们能从已有材料里学出规律，再去处理从未见过的新题。但在环境不透明、条件随时会变的任务里，只靠事前学来的材料还不够，可靠行动还要靠主动获取反馈、修正原先的判断。这就是我想讲的「亲身体验」。

# 预测下一个 token，照样能学出规律

否定大模型智能时，最常听到一句话：「它不过是在预测下一个 token。」这句话只说了它训练时在干嘛，没回答它为了猜对下一个词，到底在参数里学出了什么。

预训练拿几千亿到上万亿 token 反复喂给模型，错一次调一次权重，文字背后的统计与结构规律就一点点沉进了参数。模型当然会背下极小一部分原文，但学规律和死记硬背是两回事。再加上后面的 RLHF 和带奖励的推理训练，今天对话模型的真实本事早超出了单纯续写，光看最初的训练目标判断不了它的上限。

# 看智能，先拿一套可检验的标准

> 智能，就是能从有限经验里抽取出规律，并用这些规律去解决新问题；关键在于分清哪些只是眼前这一次的巧合，哪些能套用到别的场景。

按这个定义，光会背训练题远远不够，核心是看没见过的题能不能做对。下面三个实验都给出了正面证据：

- **Othello-GPT 学出了棋盘内部状态：**哈佛和 MIT 的 Kenneth Li 等人只给模型喂黑白棋落子序列，既不给棋盘图也不教规则，训练它猜下一步合法落子。训完后研究者从模型内部读出了完整的棋盘状态表征，手动拨动某一格棋子状态，模型预测的合法落子立刻跟着变，说明它真靠自己建出了内部世界模型来推理[<a href="https://arxiv.org/abs/2210.13382" url-type="5">Emergent World Representations, ICLR 2023</a>](https://arxiv.org/abs/2210.13382)；后续研究还证实连线性探针都能直接读出这盘棋。
- **上下文里学会举一反三：**Anthropic 发现模型训到半程，内部会长出一种叫归纳头（induction head）的电路。不用更新任何权重，只要在当前上下文给它两个例子，它就能顺着规律接着处理第三个；从两层玩具模型到千亿级大模型都能稳定看到这种相变[<a href="https://arxiv.org/abs/2209.11895" url-type="5">In-context Learning and Induction Heads, Anthropic 2022</a>](https://arxiv.org/abs/2209.11895)。
- **Grokking 证明「死记」和「泛化」有明确边界：**OpenAI 让小模型做模 97 除法，它不到一千步就把训练集背到满分，测试集却依然一塌糊涂；继续训到约一百万步时，模型突然「顿悟」，测试集正确率陡然冲上去[<a href="https://arxiv.org/abs/2201.02177" url-type="5">Grokking, OpenAI 2022</a>](https://arxiv.org/abs/2201.02177)。

这三个结果能撑住前面的判断：模型真的在学规律并用来解新题。至于逐字记忆原文，学界也早已证明确实存在少量可被提取出来的训练片段并构成隐私风险，所以准确口径是「主要学出规律，同时少量原文仍会被背下」，而不能把两者说成非此即彼。

# 「亲身体验」得落到具体行动能力上

谈「亲身体验」很容易扯进哲学玄谈。拿「烫」举例，它既能指物理温度，也能指人的痛觉。给模型接个温度传感器，它读到了 80 度，顶多算多了一条数值输入，说明不了它「感到了烫」；换成图像、声音或触觉传感器，道理一样，不能只靠任务过关就反推模型拥有主观意识。

真正值得拆解的是另一层含义，就像木匠手上的分寸：摸到木料纹路和软硬，根据凿下去的阻力调整力道，错一次下次就改。本文讨论的「亲身体验」，指的就是这种在真实交互里出手、拿结果、再修正判断的能力。

# 行动，能拿到材料里没有的新证据

前面的 Othello-GPT 证明了只要文字记录信息够全，光看别人留下来的材料也能学懂。人通过看书和看示范同样能学会很多本事，亲自下场并不是理解每件事的先决条件。

问题往往出在「当前材料信息不够」的时候。比如让机器人去拿桌面上的杯子，光看照片，根本分辨不出里面有没有装水。单凭静态画面再怎么多角度分析，都变不出杯子的实际重量。

这时机器人试着把杯子提起来一下，力传感器就会立刻补上一条新证据：原来猜它很轻，实际拽起来费劲得多，下一步就能马上加力捏稳。行动在这里起的作用很具体——把原本缺失的那块关键事实抓进眼里。

当然，拿到反馈只是第一步，归因对了才算数。杯子打滑可能是握力太小，也可能是捏偏了位置；不控制变量盲改，下一把照样掉。

至于传感器结果，完全能翻成「实测重量高于预期」传给语言模型。反馈管不管用，看它能不能补充当前材料覆盖不到的现场信息，跟它长成电压信号还是文字没关系。

# 语言模型也能靠交互攒任务经验

这套交互并不非得发生在物理世界。一个写代码的 Agent 收到报错，自己去翻日志、跑单测、对照预期改代码，就已经是在数字环境里用行动拿证据。

- **ReAct 把思考和行动交替串起来：**模型一边推理，遇到事实拿不准时就调工具或查 Wikipedia API 拿到确切信息，再回来往下推[<a href="https://arxiv.org/abs/2210.03629" url-type="5">ReAct，ICLR 2023</a>](https://arxiv.org/abs/2210.03629)。
- **Reflexion 把试错踩坑写进外置记忆：**把每轮行动反馈整理成文字存进情景记忆，下一轮不用改模型权重，在部分测试任务里就能明显少踩老坑[<a href="https://arxiv.org/abs/2303.11366" url-type="5">Reflexion，2023</a>](https://arxiv.org/abs/2303.11366)。不过这也只是系统级经验复用，远不能算模型自己学会了无限持续学习。

这也提醒我们要把「模型本体」和「Agent 系统」分开看：基础模型权重一点没动，但系统往上下文和外部记忆里添了实测证据，下一轮决策的质量就已经变了。这种经验能先帮当前任务纠偏，至于能不能安全跨任务迁移，还得靠专门验证。

同理，幻觉也不能全赖「模型没亲身经历过」。信息不够时它本可以去查，或者直接说不知道；OpenAI 的研究指出，很多胡编源自训练和评测都在奖励「猜一个答案」而不鼓励认账[<a href="https://openai.com/index/why-language-models-hallucinate/" url-type="5">Why language models hallucinate，2025</a>](https://openai.com/index/why-language-models-hallucinate/)。哪怕接了反馈，反馈本身出错或模型读歪了照样会答偏。

# 世界模型：先预测动作后果，再拿结果校对

到了物理操作这一步，系统不能只认出眼前有个杯子，还得猜出「手往左挪五厘米，杯子会怎么倒」。

JEPA 路线就在做动作条件下的状态预测：V-JEPA 2 先看互联网视频自监督学出物理规律，再补不到 62 小时的真机交互数据训出 V-JEPA 2-AC，拿去规划机械臂抓放[<a href="https://arxiv.org/abs/2506.09985" url-type="5">V-JEPA 2，2025</a>](https://arxiv.org/abs/2506.09985)。

这组结果说明「看视频学规律」和「真下手试错」本来就能配合着来：能从视频看懂的规律不必从零摔跟头，但真换进新场景还管不管用，仍要看实战检验。

所以，「亲身体验」能收成一个直接可测的标准：环境一变到材料没覆盖的地方，系统能不能挑对检查动作、抓到结果和预期的差值，并在后面少犯同一类错？

对比时要固定好基础模型和任务条件，只看有效反馈带来了什么改动；光多试几次或者空口写段反思，不算真的长了经验。

说到底，想要智能体在多变的真实环境里靠得住，就必须让行动带回来的真结果参与修正判断。
